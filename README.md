# larawang-sanaysay

Bilang isang requirement sa FIL03, PT5, nabuo ang website na ito ukol sa larawang sanaysay tungkol sa mga nagawa IS209.
Ito ay simple lamang, hindi gaanong mga litrato ang kayang storage ng isang html file, kaya compressed ang mga images sa website.

PAANO BUKSAN ANG WEBSITE NA ITO:
1. Pindutin ang larawang-sanaysay (8)
2. Hanapin sa top right ang download button
3. Mapupunta ang html file sa downloads folder
4. Double-click upang buksan ang html file sa browser
5. Right-click -> open with -> VS Code or iba pang code editor upang makita ang code
